# Welcome to LABolic!

架空の大学研究室を舞台にした、材料科学シミュレーションゲームです。
ブラウザだけで動きます（スマートフォン対応）。

**▶ [プレイする](https://shuntokita.github.io/welcome-to-LABolic/)**

装置を買い、元素を解禁し、試験片を作り、Discovery を目指します。
全21種の Discovery（実在合金11種＋架空元素合金7種＋伝説レシピ3種）の達成が
最終目標で、クリアまでの日数がスコアになります。

現役の材料研究者が、材料研究に興味を持ってもらうために一人で開発しました。
開発にあたっては生成AIを大いに援用しています。

### 素材について

`assets/` 内の画像は、すべて Google Gemini による生成物です。
生成AIの出力は、人間の創作的寄与の程度によっては著作物として保護されない
可能性があります。したがって上記の権利主張が画像にどこまで及ぶかは
不確実であり、この点については主張を留保します。

権利を主張します。

## 遊び方

ゲーム内の「⚙ 設定 → ❓ ヘルプ」に詳しい説明があります。

セーブデータはブラウザの `localStorage` に保存されます。サーバーには
送信されません（リーダーボードへのスコア送信は、プレイヤーが明示的に
操作したときのみ行われます）。

## リポジトリの構成

```
index.html                  最新版へのリダイレクト
labolic-playtest-NN.html    各バージョンの本体。単一HTMLにゲーム全体が入る
assets/                     装置画像・キャラクターアイコン
tools/                      バージョン管理・検査・リリース用スクリプト
```

過去バージョンのファイルは残していますが、開くと最新版へ転送されます。

開発手順は [CLAUDE.md](CLAUDE.md) に記載しています。

## 動作環境

モダンブラウザ（Chrome / Safari / Firefox / Edge）。
スマートフォンでの縦画面プレイに対応しています。
