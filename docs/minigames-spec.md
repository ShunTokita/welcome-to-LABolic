# 装置ミニゲーム 仕様書（ドラフト）

各装置の「肝となる作業」を模したミニゲームを作る。クリアすると、
その装置で**複数の試験片を一括処理する機能**（以下「一括処理」）が解放される。

目的は「実験」への没入感。操作は数個のボタンで済む簡単なものにする。

---

## 0. 確定事項

| 項目 | 決定 |
|---|---|
| 解放するもの | 装置ごとの一括処理（複数の試験片を一度に処理）。未クリアの装置ではロック |
| 解放の単位 | 装置ごと（12装置 × 1ゲーム） |
| 永続性 | 一度クリアすれば永久に解放 |
| 所要時間 | 1ゲーム1分以内。Lv4装置のみ2分弱（あくまで目安） |
| 時間制限 | **なし。** ゆっくりでも、作業をやり遂げればクリア |
| 3D | 合成系・プロセス系。採否は試作を見て判断。**動作の軽さが最重要の要件** |
| 開発方式 | `minigames/` に1本ずつ独立HTMLとして作り、Artifactで確認。統合は最後 |

### 所要時間の目安

| Lv | 合成 | プロセス | 分析 | 目標時間 |
|---|---|---|---|---|
| 1 | Casting | Furnace | Optical | 30〜40 秒 |
| 2 | Arc melting | Rolling | SEM | 40〜50 秒 |
| 3 | Laser Deposition | Magnetizer | TEM | 50〜60 秒 |
| 4 | Phase Shift | AGT | QAA | 90〜110 秒 |

## 1. 共通の枠組み

12本すべてで次の部分を共有する。

- **開始画面**：装置名、1行の説明、Start
- **判定表示**：SEMプロトタイプのリズムゲーム風ポップアップ
  （Excellent!!! / Great! / Good / Umm...）を全ゲームで流用する
- **結果画面**：クリア／失敗、Retry
- **クリアの保存**：localStorage。キーは既存の命名規則に合わせて
  `labolic.minigames.pt1`（仮）とし、`{ casting:true, sem:true, ... }` の形で持つ
- **一時停止・中断**：途中でやめた場合は未クリア扱い。ペナルティなし

## 2. 分析系 —「像の調整」

**クリア条件：3試料で Excellent!（像質 q ≥ 0.90）を出す。**

SEMプロトタイプ（`SEM TUNER — proto`）の描画・判定エンジンを共通で使い、
装置ごとに操作できるパラメータと見た目を変える。

### SEMプロトタイプの要点（引き継ぐ部分）

- SVGの `feGaussianBlur` を2軸で掛け、フォーカスずれ D と非点収差 a から
  2方向のぼけ s1 = |D − a|、s2 = |D + a| を作る。ぼけの軸は非点の角度に追従する
- 像質 q = 0.82 × 鋭さ + 0.18 × 階調（コントラスト・ブライトネス）
- WOBB（ウォブラ）：フォーカスを振動させ、軸ずれがあると像が横に揺れる。
  アライメントパッドで揺れを止める
- モードは NORMAL / HARD・WOBB / EXPERT の3つ。ミニゲームでは装置ごとに1つに固定する

### 光量（明るさ）・コントラストの扱い

**分析系の4装置すべてに光量の調整を付けるが、像質の評価には含めない。**
コントラストを持つ装置（SEM など）も同様に評価に含めない。
見やすさのための操作であり、合わせなくても Excellent は出せる。
プロトタイプの像質式から階調（コントラスト・ブライトネス）の項を外し、像質 = 鋭さ とする。

### 各装置

| 装置 | 操作 | 内容 |
|---|---|---|
| Optical | フォーカス、光量 | 評価はフォーカスのみ |
| SEM | フォーカス、スティグマ、光量、コントラスト | プロトタイプの NORMAL モード相当。評価はフォーカスとスティグマのみ |
| TEM | 試料傾斜（α/β のパッド）、回折フォーカス、光量 | 後述 |
| QAA | フォーカス、スティグマ、ウォブラ（軸合わせ）、光量 | プロトタイプの HARD・WOBB 相当。架空装置らしい見た目に変える |

### TEM（SAED の軸合わせ）

- 画面には回折パターン（透過スポットと回折スポットの格子）を表示する
- **試料傾斜 α/β**：晶帯軸からずれていると、ラウエ円に沿って片側のスポットだけが
  明るくなる。傾斜パッドで、パターンの強度が中心に対して対称になるまで合わせる
- **回折フォーカス**：スポットのにじみ（大きさ）を変える。合うと点になる
- 像質 = 強度の対称性 × スポットの鋭さ

### ガイド

Excellent の獲得数に応じて、評価に効く操作部にだけガイドを出す（光量などには出さない）。

| | スライダー | パッド | 吹き出し |
|---|---|---|---|
| 1問目 | 正解位置に細く光る帯 | 正解位置に光る輪 | 未調整の操作部に1つずつ（最後は Capture に「撮影しよう！」） |
| 2問目 | 広く淡い帯（中心はランダムにずらし、正解は範囲内） | 大きな淡い円（同上） | なし |
| 3問目 | なし | なし | なし |

吹き出しの文言：

| 装置 | 順番 |
|---|---|
| Optical | ピントを合わせよう！ → 撮影しよう！ |
| SEM | ピントを合わせよう！ → 形をシャープにしよう！ → 撮影しよう！ |
| TEM | パターンを対称にしよう！ → スポットを小さく絞ろう！ → 撮影しよう！ |
| QAA | WOBBを入れよう！ → 揺れを小さくしよう！ → WOBBを切ろう！ → ピントを合わせよう！ → 形をシャープにしよう！ → 撮影しよう！ |

演出（エフェクト）は今後強化する。

### 性能面の注意

プロトタイプは毎フレーム SVG フィルタを書き換えている。iOS では
`feGaussianBlur` のコストが無視できないため、**値が変わったフレームだけ再描画する**
（WOBB の振動中は除く）。

## 3. プロセス系 —「パラメータ操作」

**クリア条件：1回の処理で Excellent を出す。**

### Furnace — 石英管の真空封じ切り

操作：回す / 引く（2ボタン）。※当初案の「左右交互にリズムよく押す」は難しすぎたため変更

1. 「回す」でバーナー上の石英管を回し始める（以後は自動で回る）
2. 管が均等に温まり、くびれ（ネック）が細くなっていく。
   真空なので、軟化した管は大気圧で内側に潰れていく
3. ネックが適正な太さになったタイミングで「引く」を押して引き伸ばし、焼き切る

失敗の分岐：

| 原因 | 結果 |
|---|---|
| 回転にムラがある（同じボタンの連打、間隔の乱れ） | 片側だけが薄くなって穴が開く（リーク） |
| 引くのが早い（ネックがまだ太い） | 引き伸ばした部分の肉が薄くなり、リーク |
| 引くのが遅い（加熱しすぎ） | 管が垂れて曲がる |

判定：均一度 × 引きのタイミング。

実装メモ（試作2）：
- 難易度を下げ、引くタイミングに集中する形にした。操作は「回す」「引く」の2ボタン
- 「回す」を1回押すと、管は自動で回り続ける。押さずに放置すると、炎の当たる1か所だけが過熱して穴が開く
- 管の周方向を8区画に分けて加熱を計算する（回していれば加熱ムラは問題にならない）
- 判定は実質、引くタイミングのみ。回し始めてから約20秒でネックが目標範囲に入る
- ガイド：ネック径ゲージに目標範囲を常時表示し、「回して加熱しよう！」「細くなったら引こう！」の吹き出しを出す
  （プロセス系は Excellent 1回でクリアなので、ガイドはクリアまで出し続ける）

### Rolling — ロールギャップ調整によるマルチパス圧延

操作：ギャップ − / ギャップ ＋ / 通す（3ボタン）

- 目標：初期板厚 h₀ から指定の圧下率（例：2.00 mm → 1.00 mm、50%）にする
- **出側板厚はロールギャップより厚くなる。** 主因はミルの弾性変形（ミルストレッチ）で、
  ゲージメータ式 h = S + P / M に従う（S：ギャップ、P：圧延荷重、M：ミル剛性）
- 荷重 P は「そのパスの圧下量」と「加工硬化の進み具合」で大きくなる。
  そのため**後半のパスほど、狙いより厚く仕上がる**
- 材料自体の弾性回復も加えるが、寄与は小さく設定する（金属では板厚の 0.1〜0.5% 程度）
- 1パスの圧下量には上限があり、超えると噛み込み不良になる（その回は板厚が変わらない）
- **薄くしすぎたら取り返しがつかない**ので、最後は少しずつ詰めることになる

判定：最終板厚の目標からの誤差と、パス数。
例：誤差 ±1% 以内で Excellent。薄すぎた場合は即失敗。

### Magnetizer — 超伝導マグネットの励磁

実際に装置を扱う人が「あるある」と感じる要素を中心に組む。
根拠は末尾の参考資料を参照。

操作：PSHヒーター ON/OFF、▲ランプ（長押し）、▼ランプ（長押し）、残量確認（4ボタン）

手順：

1. **PSH（永久電流スイッチ）ヒーターを ON にし、温まるまで待つ。**
   実機では少なくとも約15秒待ってから掃引する（ゲーム内では短縮する）
2. **▲ランプを長押しして電流を上げる。** 許容される掃引速度は、
   電流（＝磁場）が高い領域ほど遅くなる。速すぎると負荷メーター（コイル電圧 L·dI/dt）が
   振り切れ、**クエンチ**して失敗（演出：ヘリウムが一気に蒸発する）
3. 目標磁場で止める
4. **PSH ヒーターを OFF にし、待ってから電源側の電流を下げる**（永久電流モードへ移行）

「あるある」として盛り込む失敗：

| 操作ミス | 結果 |
|---|---|
| ヒーターを入れ忘れて掃引する | 電源の電流計は上がるのに、磁場が上がらない |
| ヒーター ON 直後、待たずに掃引する | 同上。スイッチがまだ常伝導になっていない |
| ヒーターを OFF にせず電源電流を下げる | 磁場まで一緒に下がる |
| 掃引が速すぎる | クエンチ |
| 液体ヘリウム残量を確認しない | 残量が少ない回はクエンチしやすい（ランダム） |

当面は入れない追加ステップ（将来の候補として記録）：

- **残留磁場の除去**：ゼロに戻しても、超伝導線の磁束ピン止めにより数十 Oe の
  残留磁場が残る。プラス・マイナスに振りながら振幅を減らしてゼロに戻す
  （Oscillate モード）と、残留磁場を ±5 Oe 程度まで下げられる

判定：目標磁場からの誤差、手順違反の有無。

### AGT — 試料ステージの位置調整と AGT スフィアの軸調整（架空装置）

操作：ステージ XY パッド、スフィア傾き（2軸）、開始

- 画面には回転するスフィアと、その回転軸の軌跡を表示する。
  軸がずれていると軌跡が円を描いて歳差運動する
- **ステージ位置**：試料をスフィアの中心に置く。中心からずれていると、歳差の円が大きくなる
- **スフィア軸**：傾き2軸で歳差の円を小さくする
- 2つの調整は互いに影響し合う（片方を合わせるともう片方が少しずれる）。
  実際の軸合わせのように、交互に追い込んでいく
- 軌跡が1点に収束したら「開始」でねじり処理を行う

判定：開始時点の残留ずれ。

## 4. 合成系 —「分解・清掃」

**クリア条件：清掃と組み立てがすべて終わること。** 判定は手順違反で付ける（所要時間はクリアに影響しない）。

### 共通エンジン

装置ごとに「部品」「汚れ」「特殊作業」のデータを用意し、同じエンジンで動かす。

| 工程 | 操作 | 内容 |
|---|---|---|
| 分解 | 部品をタップ | 外せる部品だけが光る。順序を守らないと外れない（ボルトより先に蓋は外れない） |
| 清掃 | 汚れの上をこする | 汚れの量が減っていく。取り残しがあると次へ進めない |
| 部品清掃 | 同上 | 外した部品を1つずつ清掃する |
| 特殊作業 | 装置ごと | 下表 |
| 組立 | 部品をタップ | 分解の逆順に取り付ける |

視点操作は ◀ / ▶ の2ボタンで回転させる。

### 各装置

| 装置 | 分解 | 清掃 | 特殊作業 |
|---|---|---|---|
| Casting | 金型 | 金型の内側をブラシで清掃 | なし |
| Arc melting | 部品 | チャンバー内、部品 | **トーチ先端の研磨**：タングステン電極の先端を砥石に当てて回し、円錐形に整える |
| Laser Deposition | レーザーヘッド、ステージ | チャンバー内、部品 | **使用済み粉末の廃棄**：ホッパーを傾け、粉をこぼさずに廃棄容器へ移す |
| Phase Shift | PhaseShift プローブ、ステージ | チャンバー、部品 | **謎のエネルギー源のチャージ**：長押しでゲージを溜め、緑の範囲で離す |
