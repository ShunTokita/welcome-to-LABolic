# Discovery 製品アイコン 発注仕様

ブラウザゲーム *welcome to LABolic* の Discovery（新合金発見）ポップアップに出す
アイコン 14 点の仕様。各合金が**実際に何に使われているか**を、デフォルメした
ドット絵で示す。

---

## 1. 納品要件

| 項目 | 値 |
|---|---|
| 枚数 | 14 枚（後述のリスト） |
| 画像サイズ | **32 × 32 px**（1ドット＝1ピクセル。拡大縮小しない） |
| 形式 | PNG、**アルファ付き**（背景は完全透明） |
| ファイル名 | 後述の `id` をそのまま使い `<id>.png` |
| 配置先 | `assets/pixel/product/` |
| アンチエイリアス | **禁止**。半透明ピクセルを作らない（輪郭・内部とも α=0 か 255 のみ） |
| グラデーション | **禁止**。色は下記パレットから選んだ単色の面で構成する |

32×32 は小さい。**1ドットの誤差が形を壊す**ので、ベクターで描いてから縮小するのではなく、
最初から 32×32 のグリッドで構成すること。

---

## 2. 表示環境（＝読みやすさの前提）

ゲーム内では以下のように表示される。ここを踏まえて明度を決めてほしい。

- **64 × 64 px に整数倍（×2）拡大**、`image-rendering: pixelated`（ニアレストネイバー）
- アイコンの下地は**クリーム色 `#FAF0D4`**、その外側のカードは `#F0E3C2`
  → **明るい背景**。白や極端に明るい色だけで構成すると輪郭が飛ぶ
- 角丸 10px の正方形、紫の枠 `#6F4EA0` が 3px
  → 角が切られるので、**四隅 2px 程度には主要な形を置かない**
- ドロップシャドウは不要（カード上に浮いているので影は描かない）

---

## 3. 描画ルール

このゲームのドット絵全体（装置14点・キャラクター26体・床）と同じ規約に従う。

1. **輪郭はシルエットの外周にのみ**、ネイビー `#2B3252`（`ink`）1px で入れる。
   形の内側に黒い線を引かない。**内部の境界は明度差（値のステップ）で表現する**。
2. **光源は左上に固定**。ハイライトは各面の左上、陰は右下。
3. 1つの面につき **明・中・暗の3階調**を基本とする。4階調以上は使わない。
4. 色は**下記パレットから選ぶ**。新色を足さない（下地のクリームと近すぎる色を
   自作すると、アイコンが背景に溶ける）。
5. **投射は「正面図＋上面」**が基本。左右対称で、消失点を持たない。
   ただしアイコンは床に置く装置と違い、**可読性が優先**。
   「この形は斜めからでないと伝わらない」場合に限り斜方を使ってよい（例：ジェットエンジン）。
6. 画面いっぱいに描かず、**上下左右 1〜2px は余白**を残す。

## 5. 実作業で判明した失敗パターン

32×32 で実際に描いて読めなかったケース。同じ轍を踏まないように。

| 症状 | 原因 | 対処 |
|---|---|---|
| シンクが**電子レンジ**に見える | 正面矩形の中に暗い矩形を置いた。それは「画面」のシルエット | 上から覗き込む構図にする。天板を手前ほど広い台形にし、ボウルの壁を底に向かって収束させる |
| ジェットエンジンが**カメラのレンズ**に見える | 円筒の前面に円形の開口＝レンズ鏡筒 | ファン面をほぼ正円で大きく残し、後退角付きブレードとスピナーの渦巻きを描く。ナセルを深く斜めに振ると手がかりが潰れる |
| 浮遊円盤が**眼球**に見える | 同心円＋明るい中心 | 中心に明色を置かない。厚み一定の板にする |
| 人工股関節が**棒付き飴／金槌**に見える | 球＋短い棒／急テーパーのステム | ステムを長く、ほぼ平行に。骨頭は相対的に小さく |
| 眼鏡が**ゴーグル**に見える | レンズが大きく、リムが太く、つるが無い | レンズを小さく、リムを細く、つるを左右に描く |
| 色の不安定な金属が**カラーバー**に見える | 1px幅の縞を多数並べた | 少数の大きな面に分割する |
| メスが**画鋲**に見える | 1px の線で描いた | 柄に幅を持たせ、刃を三角形で描く |
| 要素を重ねると**全部潰れる** | 32px に4要素を重ねた | 重ねず並置し、主役を1つ決めて他を従属させる |

---

## 6. 検収基準

1. 14 枚すべてが 32×32、透過 PNG、半透明ピクセルなし
2. パレット外の色が 1 ドットも無い
3. **64px に拡大した状態で**、説明文なしに何のアイコンか言い当てられる
4. クリーム `#FAF0D4` の上に置いて輪郭が飛ばない
5. 角丸で四隅が切られても意味が失われない
